# Project rules

Keep this app organized so a beginner can read it.

- Screens go in `pages/`.
- Shared pieces go in `components/`.
- Saving and loading goes in `data/`.
- Each file does one job.
- No file is longer than 300 lines.
- Before writing anything new, search the project to check if it already exists, and reuse it.
- After every change, push it and merge it to `main`.
